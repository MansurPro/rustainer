CPU only unless you pass another server image on the command line.

      

    

  


  

    

      
Kubernetes 
        
        
        
      

      

        A single-node k3s cluster in one --privileged container of this engine. Its data is a volume, so stopping
        and starting keeps the cluster. rustainer kube kubectl … is kubectl; rustainer kube config
        prints a kubeconfig. Needs root on a Linux host.

      

    

  


  

    

      
Extensions

      

        An extension is a stack plus the address of its page: rustainer extension install <dir>.
        This is not Docker's extension format and cannot load Docker's extensions.

      

      

    

  


  

    

      
MCP servers 
        
        
      

      

        Docker Hub's mcp catalogue. A server is an image that speaks MCP on stdin and stdout, so a client starts it
        with rustainer run -i --rm; "config" gives the exact entry to paste into the client. There is no gateway here:
        each client runs its own servers.
